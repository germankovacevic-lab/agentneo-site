# agentneo-site

Static site for **AgentNeo** — landing, privacy policy, terms of service, and OAuth callback handler.

Used to host the URLs required by third-party API consoles (LinkedIn, Google, TikTok, etc.) when registering AgentNeo's developer apps.

- 🌐 https://germankovacevic-lab.github.io/agentneo-site/
- Privacy: `/privacy.html`
- Terms: `/terms.html`
- OAuth callback: `/callback.html`

Deployed via GitHub Pages from `main`.
